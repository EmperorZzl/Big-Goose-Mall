# 图片水印功能 — 设计文档

**日期**: 2026-09-02
**项目**: 大额商城 (uni-app / Vue 2 / 微信小程序为主)

## 1. 概述

为主页新增图片加水印功能：用户选择图片（相册或拍照），配置文本水印参数（实时预览），生成带水印的图片并保存到手机相册。

### 需求确认

| 需求项 | 方案 |
|--------|------|
| 水印类型 | 文本水印 |
| 可配置属性 | 文字内容、密度、透明度、旋转角度、字体大小、颜色、位置模式 |
| 位置模式 | 平铺 / 单角 / 居中（三种） |
| 密度 | 针对平铺模式，控制行列间距 |
| UI风格 | 潮流年轻：深色背景、紫蓝渐变主色、动效 |
| 文字内容 | 预设模板（© 2024、禁止转载、仅供展示）+ 记住上次输入 |
| 图片来源 | 相册选择 + 拍照 |
| 保存流程 | 生成 → 全屏预览 → 保存到相册 → 可再次保存/返回 |

## 2. 整体架构

```
pages/index/index.vue（主容器，管理步骤切换）
├── components/
│   ├── StepIndicator.vue      # 顶部步骤指示器（3步进度点）
│   ├── ImagePicker.vue        # Step1: 图片选择器
│   ├── WatermarkEditor.vue    # Step2: 水印编辑器
│   ├── WatermarkCanvas.vue    # Canvas 渲染组件（Step2 预览 + Step3 导出共用）
│   └── PreviewSaver.vue       # Step3: 预览、保存、分享
└── utils/
    ├── watermark.js           # 水印绘制核心逻辑（纯函数，便于测试）
    └── storage.js             # 配置记忆（uni.setStorageSync / getStorageSync）
```

- 单页面实现，步骤间用条件渲染 + CSS 过渡动画切换（swiper 会导致 canvas 复用问题，不采用）。
- 组件职责单一：Canvas 封装为独立组件，绘制参数全部由父组件传入。

## 3. 页面流程与 UI

### Step 1 — 选择图片

- 顶部：应用标题「大额商城 · 水印工具」+ 步骤指示器（第1步高亮）。
- 中央：渐变虚线边框选择卡片，含图标 +「选择一张图片」提示。
- 两个入口按钮：**相册**（`uni.chooseImage` sourceType: album）、**拍照**（sourceType: camera）。
- 选中图片后自动进入 Step 2。

### Step 2 — 配置水印（核心）

- 上半部分：实时预览 Canvas（按图片宽高比自适应，绘制尺寸为缩放尺寸）。
- 位置模式切换：三个胶囊按钮「平铺 / 单角 / 居中」。
- 参数面板（自上而下）：
  1. 文字输入框（下方提供预设模板快捷标签：© 2024、禁止转载、仅供展示）
  2. 密度滑块（值范围 1–10，默认 5；仅平铺模式生效；单角/居中模式置灰）
  3. 透明度滑块（0.1–1.0，默认 0.5）
  4. 角度滑块（–45° 到 45°，默认 0°；平铺模式可用，单角/居中模式不可用）
  5. 字号滑块（12–48，对应 canvas 像素尺寸，默认 24）
  6. 颜色点选（预设色块：白、黑、灰、红、黄、青 + 自定义色弹出 uni.showActionSheet）
- 底部操作栏：左侧「重新选择」（返回 Step 1），右侧「生成水印」（进入 Step 3）。
- 参数任何变更实时刷新预览（150ms debounce）。

### Step 3 — 预览保存

- 全屏展示生成的带水印图片（`canvasToTempFilePath` 导出的临时文件）。
- 操作按钮组：
  - **保存到相册**（渐变主按钮）→ `uni.saveImageToPhotosAlbum`，成功后 toast 提示。
  - **分享给好友**（次要按钮）→ 触发微信好友分享（`uni.share` 或 `button open-type="share"`）。
  - **分享到朋友圈**（次要按钮）→ 触发朋友圈分享（图片类型）。
  - **换一张**（底部小按钮）→ 返回 Step 1。
- 保存/分享成功后显示成功状态，允许重复操作。

### 分享能力说明（微信小程序平台限制）

微信小程序**不能直接发送图片文件到聊天会话或朋友圈**，官方仅支持分享"小程序卡片"。实际方案：

- **分享给好友**: `button open-type="share"` → 触发 `onShareAppMessage`，`imageUrl` 使用带水印图片的临时路径 → 好友收到一张以水印图为封面的**小程序卡片**，点击可进入小程序。
- **分享到朋友圈**: `button open-type="share"` + `wx.showShareMenu({menus: ['shareAppMessage', 'shareTimeline']})` → 触发 `onShareTimeline`，同样以水印图为封面分享小程序页面（朋友圈打开为单页模式）。
- **真正的图片发送**: 引导用户「保存到相册」后，在微信聊天中从相册发送。保存成功 toast 中附带此提示文案。
- App 端（后续若打包 5+ App）可用 `uni.share` 的 image 类型直接分享图片文件，代码中用条件编译 `#ifdef APP-PLUS` 预留。

## 4. 核心技术方案

### 水印渲染

- 使用 uni-app `canvas` 组件；微信小程序端使用 `type="2d"` 新接口，通过 `uni.createSelectorQuery().in(this)` 获取 node。
- 绘制流程：
  1. `canvas.drawImage(tempFilePath)` 绘制原图
  2. 依据位置模式绘制文字：
     - **平铺**: 按密度换算的行列间距遍历网格，每格内 `translate + rotate + fillText`
     - **单角**: 四角之一绘制一条（默认右下角，可后续扩展角位选择）
     - **居中**: 图中心绘制一条
  3. 透明度用 `globalAlpha`，颜色用 `fillStyle`，字号、字体用 `font`
- 导出: `wx.canvasToTempFilePath`（type-2d 接口下传 canvas node）→ 临时文件路径。

### 清晰度策略

- **预览 canvas**: 按容器宽度缩放绘制（性能优先）。
- **导出 canvas**: 进入 Step 3 时用**原图尺寸**新建绘制一次再导出（清晰度无损）。

### 数据流

```
选图 → tempFilePath 存入 data
参数调整 → data 更新 → watch + debounce(150ms) → 重绘预览 canvas
「生成水印」→ 原图尺寸重绘导出 canvas → tempFilePath → Step 3 展示
「保存」→ uni.saveImageToPhotosAlbum(filePath) → 成功提示
```

### 配置记忆

- 参数对象整体存取：`uni.setStorageSync('watermarkConfig', config)`。
- 触发时机：进入 Step 2 时读取恢复；参数变更时防抖写入（500ms）。

## 5. 视觉规范

| 元素 | 规格 |
|------|------|
| 背景 | `linear-gradient(180deg, #0F0F1A, #1A1A2E)` 深色渐变 |
| 主色 | `linear-gradient(135deg, #667eea, #764ba2)` 紫蓝渐变（主按钮、激活态） |
| 强调色 | `#00F5FF` 霓虹青（步骤指示器当前点、滑块拖块） |
| 卡片 | `rgba(255,255,255,0.05)` 填充 + `rgba(255,255,255,0.08)` 边框 + 圆角 16rpx |
| 文字 | 主文字 `#FFFFFF`，次要文字 `rgba(255,255,255,0.55)` |
| 动效 | 步骤切换淡入+水平滑动；按钮按压 `scale(0.96)`；指示器点渐变过渡 |

## 6. 错误处理

| 场景 | 处理 |
|------|------|
| 相册/相机权限拒绝 | `uni.chooseImage` fail 回调 → 弹窗说明 → `uni.openSetting` 引导开启 |
| 保存相册权限拒绝 | `saveImageToPhotosAlbum` fail 且 errno 为权限类 → 同上引导；其他错误 toast 明确提示 |
| 分享失败 | 用户取消或失败时静默处理（微信官方行为），不需要额外提示 |
| 超大图片 | `uni.getImageInfo` 获取尺寸，最长边超过 4096px 时提示「图片过大，可能处理较慢」 |
| Canvas 绘制异常 | 绘制函数 try-catch，失败时 toast「生成失败，请重试」，不崩溃 |
| 空文字提交 | 文字为空时「生成水印」按钮置灰 |

## 7. 测试策略

- 微信开发者工具模拟器 + 真机预览（iOS / Android 各一台）。
- 图片适配：横图、竖图、方图、超大图（>4096px）。
- 参数边界：密度最小/最大、角度 -45°/45°、透明度 0.1/1.0、空文字。
- 分享链路：分享卡片封面是否为水印图、朋友圈单页模式打开是否正常。
- 权限拒绝 → 引导开启 → 重试的完整链路。
- 记忆功能：杀掉小程序后重进，配置恢复正确。
